# 💰 Gestor de Gastos Personales
## 📋 Descripción
Aplicación de consola para gestionar gastos personales con base de datos SQLite.
## ⚙️ Funcionalidades

Añadir gastos
Ver todos los gastos
Ver gastos por categoría
Ver el total gastado
Borrar un gasto

## 🛠️ Tecnologías

Python 3.x
SQLite3

## 🚀 Cómo usarlo

Clona el repositorio
Ejecuta python gastos.py
Sigue el menú
